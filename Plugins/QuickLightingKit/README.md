# Quick Lighting Kit 

> Part of [Oliwia's Tool Library](https://github.com/OliwiaJakubiak/OliwiasToolLibrary) | [Tool Library Site](http://oliwia-tool-library.webflow.io)

Apply professional scene lighting presets instantly with full control over sun, sky and fog values. 

---

## What it Does 

Quick Lighting Kit lets you apply professional lighting presets to any scene in seconds directly from the editor. Choose from built-in presets or configure your own sun, sky, and fog values. Eliminating the repetitive setup time involved in lighting new scenes and prototypes.

---

## Key Features

- Built-in professional lighting presets for common scenarios
- Full control over sun, sky and fog parameters
- One-click preset application directly in the editor
- Adjustable individual light properties after generation
- Works across any UE5 scene or level 

---

## Requirements 

- Unreal Engine 5.7.4 or later
- C++ project with Visual Studio (or equivalent) installed
- If your project is Blueprint-only, convert it first via *Tools -> New C++ Class*

---

## Installation 

1. Download the plugin `.zip` from the [latest release](../../releases)
2. Extract the plugin folder into your project's `Plugins` directory
3. Right-click your `.uproject` and select **Generate Visual Studio project files**
4. Open the project and click **Yes** when prompted to build
5. Enable the plugin via *Edit -> Plugins* if not already active

---

## How To Use 

1. Open the tool from **Oliwia's DevTools** menu
2. Select a lighting preset or configure your own settings
3. Hit **Apply Lighting** to set up the scene lighting
4. Adjust individual light properties after generation if needed
