# Universal Animation Template 

> Part of [Oliwia's Tool Library](https://github.com/OliwiaJakubiak/OliwiasToolLibrary) | [Tool Library Site](http://oliwia-tool-library.webflow.io)

Generate a custom Animation Blueprint with the exact states you need, skeleton assigned and variables ready. 

---

## What it Does 

Universal Animation Template generates a custom Animation Blueprint tailored to your project's needs. Pick your skeleton, tick the animation states you require, name it, and generate. The AnimBP is created with the correct skeleton assigned, variables ready and each state waiting for your animations. A fully wired example AnimBP is included as a reference at any time.

---

## Key Features

- Generate a custom AnimBP with only the states your project needs
- Skeleton assigned automatically from your Content Browser selection
- Variables pre-created and ready todrive transitions
- Configurable output folder and name
- Includes a fully wired example AnimBP for reference 

---

## Requirements 

- Unreal Engine 5.7.4 or later
- C++ project with Visual Studio (or equivalent) installed
- If your project is Blueprint-only, convert it first via *Tools -> New C++ Class*

---

## Installation 

1. Download the plugin `.zip` from the [latest release](../../releases)
2. Extract the plugin folder into your project's `Plugins` directory
3. Right-click your `.uproject` and select **Generate Visual Studio project files**
4. Open the project and click **Yes** when prompted to build
5. Enable the plugin via *Edit -> Plugins* if not already active

---

## How To Use 

1. Select a Skeleton asset in the Content Browser
2. Hit **Pick Selected Skeleton** to confirm
3. Tick the animation states you need for your project
4. Enter a name and output folder then hit **Generate AnimBP**
5. Open the generated AnimBP and drag your animations into each state
6. Hit **View Example AnimBP** at any time for a fully wired reference
