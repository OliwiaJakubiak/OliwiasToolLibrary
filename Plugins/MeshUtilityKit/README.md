# Mesh Utility Kit

> Part of [Oliwia's Tool Library](https://github.com/OliwiaJakubiak/OliwiasToolLibrary) | [Tool Library Site](http://oliwia-tool-library.webflow.io)

One-click mesh utilities for resizing, origin resetting and collision generation on Static Mesh actors.

---

## What it Does 

Mesh Utility Kit brings together the most common Static Mesh workflow operations into a single in-editor panel. Resize meshes, reset origins, and generate collision without hunting through editor menus. 

---

## Key Features

- One-click resizing of Static Mesh actors
- Origin reset utilities
- Collision generation for Static Meshes
- Configurable operation settings exposed in the editor panel
- Works on selections in the Content Browser or viewport 

---

## Requirements 

- Unreal Engine 5.7.4 or later
- C++ project with Visual Studio (or equivalent) installed
- If your project is Blueprint-only, convert it first via *Tools -> New C++ Class*

---

## Installation 

1. Download the plugin `.zip` from the [latest release](../../releases)
2. Extract the plugin folder into your project's `Plugins` directory
3. Right-click your `.uproject` and select **Generate Visual Studio project files**
4. Open the project and click **Yes** when prompted to build
5. Enable the plugin via *Edit -> Plugins* if not already active

---

## How To Use 

1. Select a Static Mesh in the Content Browser or viewport
2. Choose the utility operation you want to perform
3. Configure any settings in the Details panel
4. Hit **Apply** to process the selected mesh
